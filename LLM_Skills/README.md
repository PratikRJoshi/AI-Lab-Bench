# LLM Skills

AI/LLM skills and agent instructions for Cursor and similar AI coding assistants.

## Skills

| Skill | Description |
|-------|-------------|
| [url-truth-analyzer](./url-truth-analyzer/) | Analyzes video/audio/image content from URLs and local folders. Supports YouTube, Instagram, Facebook, Twitter/X, and LinkedIn. Transcribes with Whisper or captions. Extracts text from images via OCR + visual analysis. Supports recursive folder scanning (up to 5 levels). For medical content: EBM SORT analysis with peer-reviewed citations. For general science: claim validation with credible sources. |

## Usage

These skills are designed for use with Cursor's `.cursor/skills/` directory. Copy the skill folder into your skills directory and reference it in your agent configuration.
