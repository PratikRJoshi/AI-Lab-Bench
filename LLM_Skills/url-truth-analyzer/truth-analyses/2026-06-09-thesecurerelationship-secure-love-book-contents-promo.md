## Analysis

### Science: Claim Validation
The post is mostly descriptive (what the book contains) — those statements are unfalsifiable here but consistent with the published table of contents. The implicit empirical premise is that attachment theory and EFT-style cycle de-escalation/repair help distressed couples. This premise is well supported: EFT meta-analytic data show a large effect size (~1.3) with 70–73% of couples recovering from distress [1], and the "negative cycle" (pursue-withdraw) it describes is the validated core target of EFT Stage 1 [1]. The framing is responsible — it sells understanding and skills, not a miracle cure. Main caveat is commercial: this is the author advertising her own product.

## Verdict
The strongest claim is C2 (couples get caught in identifiable negative cycles that can be interrupted) — this is the empirically validated heart of EFT [1]. The weakest is C3, not because it's wrong but because attachment work is adjunctive rather than a primary treatment for substance abuse/serious mental illness, and the post slightly blurs that. Overall the post is an honest description of a credentialed therapist's evidence-aligned book; recommend "With caveats" purely because it is paid self-promotion, so judge claims about the book's value with that COI in mind.
